# Cyber Tetris — Synthwave World v15

Обновление v15: быстрый splash в `index.html`, объёмные голографические награды, живая энергетическая рамка, обновлённый ремастер музыки и подготовленные бесшовные лупы. `index.html` остаётся неизменной публичной точкой входа GitHub Pages; полноценная игра загружается из `game.html`, а ресурсы хранятся в `assets/`.

## Управление

### Телефон / планшет

- **Первый ряд слева — аналоговый слайдер движения.** Палец задаёт горизонтальное смещение фигуры относительно точки касания. Перемещение привязано к порогам ширины клетки с гистерезисом: неподвижное удержание не повторяет шаги, а новый шаг происходит только после осознанного сдвига пальца дальше следующего порога. При упоре в стену не накапливаются скрытые перемещения.
- **Первый ряд справа — ПОВОРОТ.** Крупная отдельная кнопка.
- **Второй ряд слева — УСКОРИТЬ.** Удержание включает мягкое падение.
- **Второй ряд справа — БРОСОК.** Мгновенное падение с эффектом удара.
- Для альбомной ориентации ширина слайдера увеличена относительно кнопки поворота; размеры кнопок и safe-area адаптируются к экрану.

### Компьютер

- `←` / `→` — перемещение; `↑` — поворот; `↓` — мягкое падение.
- `ПРОБЕЛ` — жёсткий бросок; `P` / `Esc` — пауза.
- Полный экран включается **только вручную** кнопкой ⛶. Автоматического fullscreen при старте и перезапуске нет.

## Саундтрек v12

Пять отдельных оригинальных электронных аранжировок циклически сменяются **при каждом новом уровне**:

| Уровень по кругу | Трек | Темп | Длительность |
|---|---|---:|---:|
| 1, 6, 11… | Калинка Synthwave Remix | 152 BPM | ~153,6 с |
| 2, 7, 12… | Коробейники Turbo | 148 BPM | ~157,7 с |
| 3, 8, 13… | Трепак Rave | 160 BPM | ~146 с |
| 4, 9, 14… | Cyber Overdrive 2088 | 140 BPM | ~166,6 с |
| 5, 10, 15… | Полёт шмеля DnB | 174 BPM | ~134,4 с |

- OGG используется в первую очередь; MP3 предусмотрен как запасной формат.
- Музыка декодируется через Web Audio и хранит только активный трек и соседний предзагруженный трек в декодированном кэше, чтобы не занимать чрезмерно много памяти телефона.
- Переключение планируется к следующей музыкальной фразе и использует 2,25-секундный кроссфейд. Каждый трек подготовлен с бесшовной циклической областью.
- Позиция и состояние воспроизведения учитываются при паузе/возобновлении. Браузер запускает звук после первого пользовательского нажатия — это стандартное ограничение autoplay.

## Публикация на бесплатном GitHub Pages

1. Распакуйте архив.
2. Загрузите **содержимое** папки проекта в корень репозитория: `index.html`, `assets/`, `backend/`, `README.md`.
3. В GitHub откройте Settings → Pages → Deploy from a branch → выберите ветку и `/ (root)`.
4. Откройте опубликованный HTTPS-адрес.

Не загружайте только `index.html`: ему нужны соседние папки `assets/`.

## Глобальный онлайн-рейтинг (необязательно)

Локальные рекорды и испытания работают без сервера. GitHub Pages не исполняет серверный код и не предоставляет общую БД; для глобального рейтинга подготовлен шаблон Cloudflare Workers + D1 в `backend/`.

1. Установите Wrangler и войдите в Cloudflare: `npm install -g wrangler` и `wrangler login`.
2. Создайте D1: `wrangler d1 create cyber-tetris`.
3. Скопируйте `backend/wrangler.toml.example` в `backend/wrangler.toml`, задайте `database_id` и origin вашего GitHub Pages.
4. Из `backend/` примените схему: `wrangler d1 execute cyber-tetris --file=schema.sql --remote`.
5. Разверните API командой `wrangler deploy`.
6. Укажите выданный адрес в `assets/config.js` как `apiBase`.

Для соревновательного античита потребуется серверная проверка игровой сессии; текущий шаблон предназначен для дружеского рейтинга.

## v13 — опасность, камера и мобильное управление

В версии v13 добавлены индикатор опасности по высоте стопки, краснеющее окружение при критическом заполнении поля и динамические импульсы камеры на важных игровых событиях. На мобильных устройствах можно выбрать прежний слайдер или новый плавающий джойстик в настройках (значок шестерёнки).

**Плавающий джойстик:** вверх — повернуть фигуру; влево/вправо — переместить на клетку с регулируемым автоповтором; вниз — мягкое падение, пока палец удерживается; короткий тап по центру — жёсткий бросок. В настройках также доступны чувствительность и виброотклик, если его поддерживает браузер и устройство.

Вибрация использует стандартный Vibration API и может быть недоступна, например, в некоторых версиях iOS Safari. Отсутствие поддержки не влияет на игру. Полноэкранный режим по-прежнему включается только вручную кнопкой.


## V14 — Automatic Level Overdrive

- Каждый новый уровень автоматически запускает короткую фазу OVERDRIVE (около 6,4 секунды).
- Визуальная активация: объёмный бейдж, усиление корпуса, световой скан игрового поля, солнечная аура и перспективные скоростные лучи.
- Фоновая сетка и окружение временно ускоряются, затем возвращаются к обычной скорости текущего уровня.
- Добавлен отдельный Web Audio overdrive bus: низкий суб-бас, detuned supersaw-арпеджио и широкая аккордовая подложка. Основной саундтрек не прерывается.
- Нет ручной кнопки: эффект срабатывает автоматически при переходе на новый уровень.
- Пауза замораживает длительность Overdrive; Game Over и новая партия корректно завершают его.


## V15 — Splash, Holographic Rewards & Living Energy Frame

- `index.html` теперь лёгкая загрузочная страница с собственными inline CSS/JS. Она рисуется сразу, показывает статусы загрузки и открывает `game.html` во встроенном iframe после `load`; адрес GitHub Pages остаётся прежним (`/` или `/repo/`). Для iframe разрешены `fullscreen` и `autoplay`, поэтому игровая кнопка полноэкранного режима продолжает работать.
- Браузер не ждёт загрузки всех файлов сайта перед первым отображением: первоначальная отрисовка зависит прежде всего от HTML и блокирующих CSS/JS. Лёгкая splash-страница не подключает тяжёлые игровые стили/скрипты напрямую. `load` iframe срабатывает после обработки документа и его обычных зависимых ресурсов; аудио имеет `preload=none`, поэтому композиции не задерживают готовность игры. См. MDN: Window load event и web.dev Critical Rendering Path.
- `game.html` — прежняя игровая страница с сохранённой механикой, настройками и относительными путями к `assets/`.
- На больших игровых наградах появляются объёмные hologram-карточки: T-Spin, Tetris, Back-to-Back, Perfect Clear, испытание и Overdrive. Для пересекающихся событий действует приоритет, чтобы не закрывать поле несколькими уведомлениями одновременно.
- Энергетическая рамка вокруг игрового поля теперь имеет постоянный плавный световой поток. Скорость потока и интенсивность растут с уровнем; Tetris, Perfect Clear, Overdrive и опасность дают короткие тематические всплески.
- Пять треков получили осторожную tonal-master обработку (подчёркнутый низ, чуть чище середина/верх, peak limiting) и повторный экспорт в 44,1 кГц: MP3 192 кбит/с и OGG Vorbis q6. Исходные музыкальные мастера были 32 кГц / 128–135 кбит/с, поэтому повторный экспорт не восстанавливает потерянные исходником высокие частоты; он улучшает баланс и снижает дополнительные артефакты кодирования, но не является восстановлением студийных stems.
- На границе каждого трека подготовлен 2-тактовый crossfade, привязанный к BPM. Основной Web Audio path использует точную loopStart-метку, а HTMLAudio fallback получает отдельный loop-only MP3, который зацикливается без скачка.
- Все SFX получили `preload=none`; музыка прогревается в idle после полной загрузки игры, не задерживая splash.

### Публикация v15

Загружайте в корень GitHub Pages **и `index.html`, и `game.html`, и папки `assets/` и `backend/`**. Не переименовывайте `index.html`: он остаётся точкой входа и сохраняет тот же адрес сайта.
